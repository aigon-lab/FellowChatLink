# FellowChatLink（フェイスミニブック）

合言葉で入る小さな会員部屋です。会話・プロンプト集・ツール倉庫が使えます。

## 使い方
- `index.html`（＝ `Chat.html`）を開き、合言葉で入室します。
- スマートフォンではブラウザのメニューから「ホーム画面に追加」でアプリとして置けます（PWA）。

## ファイル構成
- `index.html` / `Chat.html`：アプリ本体（CSS・JavaScript内蔵）
- `manifest.webmanifest`：PWAの名札
- `sw.js`：オフライン起動のための Service Worker
- `icon-192.png` / `icon-512.png` / `icon-maskable-512.png`：アイコン
